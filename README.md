# CivicEvents+ Project

Frontend for the CivicEvents+ API, built with HTML, Tailwind CSS and jQuery by Cherish Yusuf.

- **Demo video:** https://youtu.be/Sxpt7i0RAig
- **Frontend code and full README (setup, API base URL, role guards, backend limitations):** [frontend/README.md](frontend/README.md)
- **Backend (provided):** [backend/README.md](backend/README.md)

## Quick start
1. Create the PostgreSQL database and run `backend/migrations/001_create_tables.sql`.
2. Set up `backend/.env` and run `npm install` then `npm run dev` inside `backend` (API at http://localhost:4000/api).
3. Open `frontend/index.html` with VS Code Live Server.

Full details are in [frontend/README.md](frontend/README.md).
